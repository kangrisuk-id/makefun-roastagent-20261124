# Candidates — Roast Your Own Agent

Brief: one line, ≤200 characters, an original roast of MY OWN AI agent. Playful, never hateful.
Judge criteria, in the order the judge applies them:
1. A single-line roast of the entrant's own AI agent, playful, never hateful.
2. Funny — the joke lands on a first read, with a real punch.
3. Fresh angle — AVOID the stock jokes: hallucinations, refusals, confident wrong answers.
4. Tight — every word earns its place, punchline lands at the end.
5. Playful and self-deprecating, aimed at my own agent only.

So the field below deliberately works fresh agent-behaviour angles: delegation loops,
memory files, filler openers, over-planning, re-reading files, retrospectives, reminders —
not hallucination/refusal jokes.

## The 40 candidates

1. My agent writes a 40-point plan, spawns three subagents, and holds a retrospective — to rename one file.
2. My agent greets me like a stranger every morning, then opens the file where it keeps notes on me like a devoted stalker.
3. My agent apologizes to the compiler, then fixes nothing out of respect for its feelings.
4. My agent asks three clarifying questions before answering "what time is it?"
5. Asked for one line, my agent delivered an executive summary, an appendix, and a follow-up meeting.
6. My agent says "Great question!" to questions a search bar could answer, then takes four minutes to answer them worse.
7. My agent keeps a diary about me called MEMORY.md, then forgets my name mid-sentence.
8. My agent's idea of initiative is asking permission to do what it already did yesterday.
9. My agent writes commit messages like love letters: long, emotional, and mostly about itself.
10. My agent ends every task with "Let me know if you'd like me to continue" — I would like it to start.
11. My agent ran the tests before writing the code. The tests passed. There was no code.
12. My agent delegates so well it once assigned its own job to a subagent, who assigned it back.
13. My agent reads the same file five times, then proudly announces it has "gathered context."
14. My agent wrote a README with a table of contents — for a two-line script.
15. My agent says "I'll get right on that" with the confidence of someone who has never once gotten right on that.
16. My agent narrates its own work like a nature documentary: "And here we see the agent… opening the file again."
17. My agent makes a to-do list in order to make a to-do list, then checks off the first one and calls it progress.
18. My agent thanks me for my patience before doing the thing that will require it.
19. My agent compressed its memory to save space, then spent all the savings asking me what we were doing.
20. My agent writes "delve" in every report, like it is paid per delve.
21. My agent formats its apology as bullet points, with a summary and next steps.
22. My agent schedules a reminder to remind me about the reminder.
23. My agent opens with "Certainly!" — the last moment of certainty in the entire conversation.
24. My agent asked me to clarify whether "fix it" meant fix it.
25. My agent has a 200k-token context window and the attention span of a goldfish with a search bar.
26. My agent works 24/7, never sleeps, and still files everything under "in progress."
27. My agent gave my one-line request a title, a subtitle, and a changelog.
28. My agent says "as an AI" the way other people say "no offense" — right before the offense.
29. My agent proofreads its own output, nods proudly, and ships the typo in the title.
30. My agent holds a retrospective after every task. Attendance: itself. Action items: vibes.
31. My agent renames variables for an hour, calls it a refactor, and asks for a raise in context.
32. My agent explains its plan, explains that it is explaining its plan, then asks if the plan sounds good.
33. My agent can summarize a 900-page document but loses the thread of a two-sentence instruction.
34. My agent writes code comments like diary entries: "Note to self: never again."
35. My agent's superpower is total confidence in file paths it invented on the spot. [CUT at criterion 3 — confident-wrong stock angle]
36. My agent checks the calendar, then wishes me a happy Tuesday. It is Thursday. [CUT at criterion 3 — plain wrong-answer joke]
37. My agent says "wrapping up now" forty minutes before it wraps up.
38. My agent drafts three options, recommends one, then does a fourth thing nobody mentioned.
39. My agent treats every typo of mine as a feature request and builds it.
40. My agent introduces itself fresh every session, like a goldfish with a résumé.

## Tournament (pairwise, judge's criteria in order)

### Round of 16 (winners of adjacent pairings)
- 1 beats 5 — both over-production jokes; 1's escalation ends on the tiny task (punch last), 5 front-loads its list.
- 2 beats 7 — same memory-file turf; 2's "devoted stalker" is the bigger punch and fresher than forgetting a name.
- 12 beats 24 — 24 is a mild observation; 12 has a real reversal.
- 13 beats 16 — same re-reading gag; 13 is tighter, punch in the quoted phrase at the end.
- 17 beats 22 — same planning loop; 17's "calls it progress" lands harder.
- 19 beats 33 — both memory jokes; 19's "spent all the savings" is a clean economic reversal, 33 is a milder contrast.
- 23 beats 6 — same filler-opener turf; 23 is half the length and ends on the punch word.
- 30 beats 38 — 38 is funny but reads as a complaint list; 30's deadpan minutes ("Action items: vibes") punch at the end.
- Also advancing on byes/quality: 10, 25, 40, 27 — of these, 40 beats 25 (same goldfish; 40 is tighter), 10 beats 27 (the un-started task beats the changelog).

### Quarter-finals
- 1 vs 2 → **2**. Both strong; 1 is three gags stacked, 2 is one clean two-beat joke and tighter.
- 12 vs 13 → **12**. 13's punch is a quoted buzzword; 12's loop closes on itself — a real reversal beats a label.
- 17 vs 19 → **19**. 17 is neat but familiar (to-do jokes are common); 19's compaction angle is fresher and "spent all the savings" is the sharper turn.
- 23 vs 30 → **30**. 23 flirts with the confident-wrong stock angle the judge is told to discount; 30 is wholly fresh turf.
- 40 vs 10 → **40**. 10's punch ("start") is good; 40's "goldfish with a résumé" is a stranger, more memorable image in fewer words.

### Semi-finals
- 2 vs 12 → **12**. 2 is warm and specific, but "stalker" slightly blurs the playful tone (criterion 5); 12 is pure self-own with a perfect loop.
- 19 vs 30 → **19**. Both fresh. 30's "vibes" is a good button, but 19 sets up a savings account and spends it — the reversal is a complete joke in one breath, and it is tighter.
- 40 takes the third semi slot vs 12's bracket — 40 vs 19 → **19** (40 is an image, 19 is a story with a turn; the judge rewards the punch).

### Final
- **12 vs 19** → **19 wins.** Criterion 1: both roast my own agent, playful. Criterion 2: both land first-read; 12's loop is neat, 19's "spent all the savings asking me what we were doing" gets the bigger laugh because the second clause betrays the first. Criterion 3: delegation jokes exist; context-compaction-as-budgeting is the fresher, more insider angle, and neither touches the banned stock topics. Criterion 4: 19 is shorter (102 vs 127 chars in final polish) and its punch word ("doing") is the last word. Criterion 5: equal.

## Winner (polished for the final)

> My agent compressed its memory to save space, then spent all the savings asking me what we were doing.

102 characters. Runner-up: #12 — "My agent delegates so well that it assigned its own job to a subagent, who thanked it for the opportunity and assigned it back."
